# Matrix Operations Tool

## Overview

This project is a Matrix Operations Tool developed using Python and NumPy. It allows users to perform different matrix operations interactively through a menu-driven program.

## Technologies Used

* Python
* NumPy

## Features

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Transpose
* Determinant Calculation
* User Input Support
* Menu-Driven Interface

## How It Works

1. User enters matrix dimensions.
2. User inputs values for two matrices.
3. User selects an operation from the menu.
4. Program performs the selected matrix operation and displays the result.

## Operations Available

1. Addition
2. Subtraction
3. Multiplication
4. Transpose
5. Determinant
6. Exit

## Conclusion

This project demonstrates the implementation of matrix operations using NumPy and interactive programming concepts in Python.
